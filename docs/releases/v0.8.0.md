## Memory Path Engine 0.8.0

First public PyPI release of **memory-path-engine**.

### Install

```bash
pip install memory-path-engine
# optional: pip install 'memory-path-engine[embed]'
mpe doctor
```

PyPI: https://pypi.org/project/memory-path-engine/0.8.0/

### Highlights (M1–M8)

- Local palace CLI (`mpe`) + MCP closed loop + Docker stdio MCP
- Hybrid retrieval with pluggable embeddings (`ngram` default / optional `fastembed`)
- LongMemEval-S full public KPI tables; hybrid NDCG aligned via seed rerank (M7)
- Trusted Publisher release workflow + `scripts/release.sh`

See [CHANGELOG.md](https://github.com/ly85206559/memory-path-engine/blob/master/CHANGELOG.md) for the full product timeline.
