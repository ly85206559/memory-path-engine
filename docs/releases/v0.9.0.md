## Memory Path Engine 0.9.0

Product **M10**: HotpotQA mid-slice public KPI + denser retrieval tooling.

### Install

```bash
pip install -U memory-path-engine
# optional dense: pip install 'memory-path-engine[embed]'
mpe doctor
```

### Highlights

- Committed HotpotQA medium64 KPI (`hybrid` leads on ngram; `fastembed` wins on comparison questions)
- HotpotQA download falls back to HuggingFace Hub when the CMU URL times out
- Optional embedding disk cache: `MPE_EMBEDDING_CACHE_DIR`

See [CHANGELOG.md](https://github.com/ly85206559/memory-path-engine/blob/master/CHANGELOG.md).
